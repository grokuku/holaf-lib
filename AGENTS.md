## Conventions partagées (écosystème holaf)

Ce dépôt **héberge** l'espace de conventions partagées de l'écosystème :
`/projects/holaf-lib/docs/conventions/` — index dans `docs/conventions/README.md`,
première convention dans `docs/conventions/pi-sdk.md` (intégration du SDK Pi).

Avant d'introduire ou de modifier un composant, une intégration ou un outil,
consulter ces conventions. **Une seule source de vérité — ne pas recopier les
conventions dans les projets ; toute nouvelle convention s'ajoute ici** (voir la
procédure dans `docs/conventions/README.md`).
